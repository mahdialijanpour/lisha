# لیشا — React + Vite

فروشگاه فارسی و راست‌به‌چپ با رنگ بنفش لیشا و چیدمان الهام‌گرفته از للفی.

## اجرا

```sh
npm install
npm run dev
npm run build
npm test
```

## امکانات

- خانه، فروشگاه، دسته‌بندی، محصول، چاپ دلخواه، سبد، پیش‌نویس سفارش، پروفایل محلی، علاقه‌مندی، درباره، تماس، FAQ، نظرات و مجله.
- جستجو و مرتب‌سازی، انتخاب سایز و تعداد، سبد پایدار در مرورگر.
- پیش‌نمایش دورس یا توت‌بگ با رنگ دلخواه، بارگذاری PNG/JPG/WebP تا ۲ مگابایت و تنظیم اندازه چاپ.
- طراحی واکنش‌گرا، دیالوگ قابل استفاده با صفحه‌کلید و پشتیبانی از کاهش حرکت.

## پیش از فروش واقعی

این پروژه فرانت‌اند قابل استفاده است. قیمت‌ها و مشخصات نمونه‌اند. پرداخت، احراز هویت، موجودی، آپلود سرور، مدیریت سفارش و ارسال هنوز بک‌اند ندارند. فرم پیش‌نویس فقط در همین مرورگر ذخیره می‌کند و این موضوع در رابط مشخص است. قوانین تجاری و ابعاد باید توسط صاحب فروشگاه تأیید شوند. برای استقرار SPA، مسیرهای ناشناخته‌ی سرور باید به index.html برگردند.

## منابع

- تصاویر شش هودی: پوشه artwork در چت «چاپ همه طرح‌ها روی هودی مشکی»؛ فایل‌های اصلی دست‌نخورده باقی مانده‌اند.
- تصویر هرو و توت‌بگ: تولید اختصاصی با ابزار داخلی imagegen؛ تصویر توت‌بگ نمونه‌ی طراحی است.
- خروجی‌های بهینه‌شده در `public/assets/hero.webp` و `public/assets/tote.webp`؛ متن کامل پرامپت‌ها در `scripts/image-prompts.json` است. نسخه‌های اصلی در `assets-original/` نگه‌داری شده‌اند.
- لوگو، گلِ خندون و تصویر وکتور دورس: SVG اختصاصی پروژه.
- فونت تیتر Pofak از فایل عمومی سایت مرجع lelefi.com مطابق درخواست کاربر؛ وضعیت مجوز وب برای انتشار تجاری باید با صاحب فونت بررسی شود. فونت متن Vazirmatn از Google Fonts.
- صفحه اینستاگرام از سایت فعلی لیشا: https://instagram.com/lishacrafts

پالت و چیدمان پایه در `src/styles.css`، ظاهر جدید کارت‌ها و منوی راست‌به‌چپ در `src/refinements.css`، صفحه محصول و رسید سبد در `src/shopping.css`، منو و سبد شناور در `src/navigation.jsx`، محصولات در `src/data.js` و مسیرها در `src/main.jsx` قابل تغییرند.

## بررسی انجام‌شده

بیلد production و دو تست منطق سبد موفق بودند. در مرورگر، جستجو، انتخاب سایز و تعداد، سبد، ذخیره پیش‌نویس، منوی موبایل، علاقه‌مندی و بارگذاری تصویر سفارشی بررسی شدند. عرض موبایل ۳۹۰ پیکسل و نمای دسکتاپ بازبینی شده‌اند.

پیش‌نمایش خصوصی Sites ثبت شد، اما همگام‌سازی سورس به علت خطای TLS شبکه به میزبان Git انجام نشد؛ نسخه‌ی آنلاین منتشر نشده است. شناسه‌ی همان پروژه در `.openai/hosting.json` حفظ شده تا انتشار بعداً بدون ایجاد پروژه‌ی تکراری ادامه پیدا کند.
